# Como ensinar informática para deficientes visuais — Dialogando

**Link:** https://dialogando.com.br/sustentabilidade/como-ensinar-informatica-para-deficientes-visuais/

## Resumo

Artigo que discute métodos e ferramentas para ensinar informática básica a pessoas com deficiência visual em ambientes de ensino inclusivos. Destaca dois tipos de dispositivos táteis/físicos de alto custo — displays braile (R$ 15.000–25.000) e impressoras braile (R$ 24.000–39.000) — que exigem treinamento especializado, contrapondo-os a alternativas gratuitas e mais acessíveis: o **Dosvox**, sistema desenvolvido na UFRJ com síntese de voz e atalho de ativação (ctrl+alt+d), que permite uso independente do computador para e-mail, textos, planilhas, jogos e pesquisas; e o **NVDA**, leitor de tela de código aberto que também é ensinado em cursos de informática para cegos junto com o Virtual Vision. Um ponto pedagógico central do artigo é que o teclado é o meio de navegação essencial (o mouse é dispensável), com o uso das marcas físicas nas teclas F e J como referência tátil de posicionamento das mãos. O artigo também recomenda evitar depender exclusivamente de teclados/dispositivos braile especializados, para preparar o aluno a operar qualquer computador padrão.

## Relevante para o projeto Tacta

- Reforça um princípio de design direto para o site: toda a experiência (incluindo o chat de IA) deve ser 100% operável via teclado, sem exigir mouse — navegação por Tab/Shift+Tab, atalhos claros, ordem de foco lógica.
- Sugere testar o site do Tacta tanto com NVDA quanto idealmente considerar compatibilidade/menção ao Dosvox, já que ambos são citados como ferramentas padrão de ensino de informática a pessoas cegas no Brasil — ampliando a base de leitores de tela testados além do NVDA.
- A ideia de "preparar o aluno para operar qualquer computador padrão" (não depender de hardware especial) é coerente com a proposta do Tacta de ensinar robótica/eletrônica via um cubo físico de baixo custo somado a um site que funciona com ferramentas de acessibilidade já disponíveis gratuitamente no navegador/SO do usuário (Web Speech API, leitores de tela gratuitos), evitando qualquer dependência de software pago.
- Pode inspirar um pequeno "guia rápido de navegação por teclado" no próprio site do Tacta, explicando atalhos disponíveis no chat e na audiodescrição por componente.
