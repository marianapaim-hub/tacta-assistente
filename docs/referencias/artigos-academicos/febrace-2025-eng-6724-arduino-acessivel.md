## Resumo

Quando o curso técnico em desenvolvimento de sistemas da instituição recebeu seu primeiro estudante cego, ficou evidente que "a plataforma Arduino não foi pensada para esse público": as ferramentas de programação (software) já têm alguma acessibilidade, mas o hardware — placas, cabos, componentes — não tem nenhum elemento tátil ou informativo em braile.

A solução foi criar **cápsulas adaptativas para o Arduino UNO** com:
- Textos em alto relevo para identificação tátil
- Inscrições em braile dos componentes
- Conectores de pressão que facilitam a manipulação tátil

Um ponto importante: a solução não altera a nomenclatura original do fabricante — só adiciona uma camada tátil/braile sobre o hardware existente. O protótipo foi validado com pessoas cegas e de baixa visão, com apoio da ADEVOSC (Associação de Deficientes Visuais do Oeste de Santa Catarina).

## Relevante para o projeto Tacta

- É essencialmente o **mesmo problema que o Tacta resolve no hardware** — vale citar como projeto correlato/precedente na apresentação do Future Lab, mostrando que o Tacta se conecta a uma necessidade real e documentada.
- Reforça que a nomenclatura dos componentes deve seguir o padrão do fabricante/já estabelecido (relevante para o "protocolo padrão" que o mentor sugeriu — ver nota de reunião de 24/07).
- O fato de terem validado com uma associação de pessoas cegas é um modelo de processo de teste que vale replicar antes da apresentação (ainda que em escala menor).
