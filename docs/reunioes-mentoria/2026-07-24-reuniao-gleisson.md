# Reunião com mentor (Gleisson) — 24/07/2026

## 1. Sugestão: chat também ensinar lógica de programação/código

Além de responder perguntas de robótica e ensinar montagem de circuitos simples, o chat com IA deveria também ser capaz de **gerar códigos e ensinar a lógica por trás deles**, para que a pessoa aprenda (ou pelo menos entenda melhor) programação, não só eletrônica/montagem.

> Nota: isso amplia o escopo definido no README (que hoje foca em "poucos circuitos simples no MVP"). Ver observação abaixo sobre impacto no prazo.

## 2. Sugestão: "protocolo"/representação padrão dos componentes do Tacta

Como a placa física tem vários componentes e pinagens, nomeados e indicados por braile diretamente na placa, a ideia é criar uma representação padronizada desses componentes dentro do software (uma espécie de protocolo ou linguagem própria do Tacta). Isso deixaria o site mais robusto e com menos erros, servindo como fonte única de verdade tanto para a audiodescrição quanto para o chat com IA.
